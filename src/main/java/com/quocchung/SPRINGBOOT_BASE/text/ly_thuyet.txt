- Cái Pattern luôn chỉ dùng được để validate String, còn nhwuxng thằng cu còn lại thì
không thể dùng được.

  + NHƯ NÀY LÀ BỊ LỖI +
  @Pattern(regexp = "^(ACTIVE|INACTIVE|NONE)$", message = "Status must be ACTIVE, INACTIVE or NONE")
  private UserStatus status;


Ý nghĩa của việc trả về true:
    Dữ liệu hợp lệ → sẽ không có lỗi validation, tiếp tục xử lý bình thường.
    Trong form đăng ký, nếu một field như "giới tính" có giá trị là "MALE" và "FEMALE" được chấp
    nhận, mà người dùng nhập "male" thì .toUpperCase() sẽ thành "MALE" và được chấp nhận → true.

Ý nghĩa của việc trả về false:
Dữ liệu không hợp lệ → sẽ gây ra lỗi validation, và nếu bạn dùng Spring hoặc Jakarta EE thì hệ thống
ksẽ trả lại lỗi cho người dùng (thường là HTTP 400 hoặc hiện thông báo lỗi trên UI).

public class ResponseStatus {
       private String code;
       private String message;
       private String label;

       public ResponseStatus() {
       }

       public ResponseStatus(String code, String message, String label) {
              this.code = code;
              this.message = message;
              this.label = label;
       }

       /*- Khởi tạo đối tượng ngay trong class khi có hàm khởi tạo -*/
       public static final ResponseStatus SUCCESS_STATUS = new ResponseStatus(
           SUCCESS_CODE,
           SUCCESS_MESSAGE,
           SUCCESS_LABEL
       );
}  => CÁCH DÙNG: ResponseStatus.SUCCESS_STATUS.getCode() + " "
               + ResponseStatus.SUCCESS_STATUS.getMessage() + " "
               + ResponseStatus.SUCCESS_STATUS.getLabel()
